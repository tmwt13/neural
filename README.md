# Neural Network
Very simple feed forward neural network (FFNN) writen in C from scratch.

## Examples included
- XOR
- Interpolation between letters
- Interpolation between numbers

## Disclaimer
This project come out of pure curiosity. It is very interesting to see how the NN manages to capture non
linear geometric shapes in order to be able to morph (in some latent space) between them.

## Usage
To use this a build of Raylib is needed, which is (except for the header) not provided with in this repo.
